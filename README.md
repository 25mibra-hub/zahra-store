# متجر زهرة | Zahra Natural Products Store 🌿

متجر إلكتروني لمنتجات زهرة الطبيعية (الإسكندرية): كتالوج بـ ٨٠ منتج بصورهم وأسعارهم، سلة مشتريات، وإتمام الطلب عبر واتساب.

## التشغيل

التطبيق static بالكامل (HTML/CSS/JS من غير أي build step):

- **محليًا:** افتح `index.html` مباشرة في المتصفح، أو شغّل سيرفر بسيط:
  ```bash
  python3 -m http.server 8000
  # ثم افتح http://localhost:8000
  ```
- **GitHub Pages:** من إعدادات الريبو → Pages → اختار البرانش `main` والمجلد `/ (root)`، وهيشتغل على `https://<username>.github.io/<repo>/`

## المحتوى

- `index.html` — التطبيق كله (الواجهة + بيانات المنتجات + منطق السلة والطلب)
- `photos/p/` — صور المنتجات الـ ٨٠
- `photos/zahra-botanical.png` — صورة الواجهة

## إزاي بيشتغل الطلب

العميل بيضيف منتجات للسلة، يكتب اسمه ورقمه وعنوانه، ويضغط "إتمام الطلب عبر واتساب" — بيتفتح واتساب برسالة فيها تفاصيل الطلب والإجمالي جاهزة للإرسال على رقم المتجر (+201019558330). مفيش دفع أونلاين.

## تعديل المنتجات والأسعار

بيانات المنتجات موجودة في آخر `index.html` جوه `const CATEGORIES = [...]` — كل منتج ليه `name` و`price` و`photo` و(اختياري) `detail`. عدّل السعر أو الاسم واحفظ الملف وبس.
